# 🌐 Modern Responsive Website

This is a responsive multi-page website built using **HTML**, **CSS**, and **JavaScript**. It features a fixed navbar with scroll effects, image background sections for each page, and a clean, professional layout.

---

## ✨ Features

- ✅ **Responsive Navigation Bar**
  - Fixed at top
  - Changes background color on scroll for better visibility

- 🖼️ **Full-Page Background Images**
  - Each section has a unique full-screen image background
  - Scrollable with improved text readability

- 🎨 **Improved Readability**
  - Semi-transparent overlays on text for better contrast
  - White-colored text with modern typography

- 📝 **Contact Form**
  - Basic form with confirmation message
  - Simulated form submission using JavaScript

- 📂 **Multiple Pages**
  - Home
  - About
  - Services
  - Portfolio
  - Blog
  - Contact
